# منهل | MANHAL

منصة تعليمية عربية **RTL** تربط **المدارس** و**أولياء الأمور** بـ**المعلمين والمعلمات**:
بحث مرتب حسب المطابقة، نشر وظائف، طلب معلم عاجل، ملفات مهنية موثّقة، ولوحات تحكم لكل دور.

> موقع ثابت (HTML + CSS + JavaScript) — بدون بناء أو تثبيت. افتح `index.html` مباشرة.

---

## التشغيل

```bash
# 1) فتح مباشر
start index.html

# 2) أو تشغيل خادم محلي (أفضل، لأن بعض المتصفحات تمنع بعض السلوكيات عبر file://)
npx serve .
# أو
python -m http.server 8080
```

ثم افتح: `http://localhost:8080`

## المزايا التقنية

- **عربي RTL افتراضي + إنجليزي LTR** بضغطة واحدة، مع حفظ الاختيار في `localStorage`.
- مكونات قابلة لإعادة الاستخدام: هيدر، فوتر، بطاقة دور، بطاقة معلم، شارة توثيق، شارة توفر، حالة فارغة، Modal، Toast.
- بحث فعلي يعمل على البيانات التجريبية: فلترة + ترتيب + مطابقة + حالة فارغة.
- حفظ المعلمين في `localStorage` ويظهر في لوحات التحكم.
- متجاوب: 4/8/12 عمود (جوال / تابلت / كمبيوتر).
- إتاحة: `skip-link`، `aria-*`، حالات focus، عدم الاعتماد على اللون وحده (نقطة + نص).

## ملاحظات

- كل البيانات **تجريبية** للعرض فقط، ولا توجد معلومات شخصية حقيقية.
- لا توجد قاعدة بيانات أو مصادقة حقيقية: تسجيل الدخول تجريبي ويحفظ الحالة محلياً.
- شارة «موثّق» لا تُعرض إلا عند وجود حالة توثيق في البيانات.
- الدفع غير مضمّن في هذه النسخة، تماشياً مع قرارات دراسة UX.

## الخطوات التالية المقترحة

1. ربط الواجهة بـ API حقيقي (مصادقة، معلمون، طلبات).

3. رفع مستندات التوثيق + سير عمل مراجعة.

5. ترجمة كاملة لكل النصوص الطويلة (السياسات، الأسئلة).
