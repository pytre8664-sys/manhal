## 📖 نظرة عامة (Overview)

**منصة وصل التعليمية** هي منصة رقمية متخصصة ومصممة لخدمة المجتمع التعليمي في **مدينة المكلا وضواحيها بمحافظة حضرموت**.
تهدف المنصة إلى تسهيل وتسريع عملية التوظيف والتعاقد التدريسي من خلال الربط المباشر والذكي بين:
1. **المدارس والمراكز التعليمية بالمكلا**: لنشر الوظائف الشاغرة، إدارة المتقدمين، وطلب معلمين بدلاء عاجلين لحالات الطوارئ.
2. **المعلمين والكوادر التدريسية**: لبناء ملف مهني موثق، عرض التخصصات والخبرات، وتلقي عروض التدريس المناسبة.
3. **أولياء الأمور**: للبحث عن أفضل المعلمين الخصوصيين لأبنائهم وفق الحي والمرحلة والمادة الدراسية.

## 🏗️ البنية التقنية (Tech Stack)

تم بناء المنصة وفق معايير برمجية نظيفة وخفيفة تعتمد على أعلى درجات الأداء والاستقلالية:
* **بيئة التشغيل:** Node.js (v24.x / متوافق مع v18+)
* **خادم التطوير المحلي:** خادم مبني بمكتبات Node.js القياسية (`http`, `fs`, `path`) بدون أي حزم خارجية ثقيلة، يدعم إعادة التوجيه الفوري (SPA Fallback).
* **إدارة الواجهات (Frontend SPA):** Vanilla JavaScript (ES6+) بنظام محرك توجيه خفيف وسريع (`WaslRouter`).
* **التصميم والأنماط:** Tailwind CSS (عبر CDN) مع تخصيص الرموز اللونية وهوية العلامة (`css/theme.css`).
* **الخطوط والأيقونات:** Google Fonts (`Noto Kufi Arabic`, `Plus Jakarta Sans`) و Material Symbols.
* **دعم اللغة والاتجاه:** دعم كامل للغة العربية والاتجاه من اليمين لليسار (`dir="rtl" lang="ar"`).

## 🚀 متطلبات التشغيل والبدء السريع (Quick Start)

### المتطلبات الأساسية
* مثبت **Node.js** (الإصدار 18 أو أحدث — البيئة الحالية مثبت عليها `v24.21.0`).
* أداة **Git** للتحكم في الإصدارات (`v2.56.0` مثبتة).

### 1. تشغيل خادم التطوير المحلي
لإطلاق الخادم ومعاينة المنصة محلياً، نفّذ الأمر التالي:

```powershell
# عبر Node.js مباشرة:
node server.js

# أو عبر npm (في PowerShell بنظام Windows):
npm.cmd start
```

بعد التشغيل، افتح المتصفح على الرابط:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🧪 حزمة الاختبارات والتحقق الآلي (Testing)

تحتوي المنصة على حزمة اختبارات داخلية مؤتمتة تتحقق من:
1. وجود وسلامة كافة الملفات الأساسية وهيكل المشروع.
2. اكتمال قوالب الشاشات الـ 12 وحجم محتواها.
3. صحة تسجيل الواجهات في `window.WASL_VIEWS`.
4. سلامة مسارات الانتقال التفاعلي (`data-path`) وخلوها من أي روابط مكسورة.
5. التحقق الصارم من حصر النطاق الجغرافي لمدينة **المكلا** حصراً.
6. محاكاة أداء الانتقالات بين الشاشات ومسارات التنقل الرئيسية.

لتشغيل الاختبارات:
```powershell
npm.cmd test
# أو
node js/test_suite.js
```

> **النتيجة الحالية:** 58 فحصاً ناجحاً من إجمالي 58 (100% Pass Rate).

## 🗺️ الواجهات الـ 12 المتاحة

1. **الرئيسية العامة (`home`):** ترحيب واستعراض الخدمات والمزايا.
2. **اختيار المسار (`role-select`):** التوجيه الذكي (مدرسة / معلم / ولي أمر).
3. **لوحة تحكم المدرسة (`school-dashboard`):** إدارة الكادر والشواغر.
4. **بوابة ولي الأمر (`parent-hub`):** حجز الدروس ومتابعة المعلمين.
5. **لوحة المعلم (`teacher-workspace`):** متابعة طلبات التدريس والجدول.
6. **دليل المعلمين (`find-teachers`):** بحث متقدم وفلاتر تخصصية ومكانية داخل أحياء المكلا.
7. **الملف المهني (`teacher-profile`):** سيرة المعلم وتقييماته ونماذج أعماله.
8. **طلب التواصل (`contact-request`):** نموذج حجز وتواصل مباشر.
9. **الطلب العاجل (`urgent-request`):** نظام الاستجابة السريعة للمدارس.
10. **نشر وظيفة (`post-job`):** استمارة إضافة شاغر تعليمي.
11. **مصفوفة المفاضلة (`applicant-eval`):** تقييم المرشحين بالمعايير والدرجات.
12. **الرئيسية المباشرة (`home-alt`):** شاشة رئيسية تركز على البحث اللحظي.
