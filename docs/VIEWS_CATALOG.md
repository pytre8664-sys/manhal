## ملاحظة هندسية حول التزامن (Sync Note):
كل تعديل يطرأ على أي ملف داخل مجلد `views/` يجب أن ينعكس بدقة داخل كائن `window.WASL_VIEWS` في `js/views.js`، ويمكن التأكد من سلامة التزامن عبر تشغيل:
```bash
npm test
```
