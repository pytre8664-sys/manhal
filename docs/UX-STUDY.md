.1 ملخص المشروع
وصل التعليمية منصة رقمية تربط المدارس وأولياء الأمور بالمعلمين المناسبين، وتساعد المعلمين
على الوصول إلى فرص تدريس. تركز المنصة على السرعة والثقة وسهولة الاستخدام، مع مسار خاص
للاحتياجات المدرسية العاجلة.
الفئات الرئيسية
• المدارس: البحث عن معلمين، نشر وظائف، وطلب معلم بشكل عاجل.
• أولياء الأمور: البحث عن مدرس خصوصي أو إرسال طلب عند عدم العثور على تطابق مناسب.
• المعلمون: إنشاء ملف مهني، تحديد التوفر، استقبال طلبات التواصل والتقدم للطلبات العاجلة.
القيمة الأساسية
إيجاد المعلم المناسب بسرعة، عبر نتائج مرتبة حسب مدى المطابقة، وملفات واضحة، وتوثيق قابل
للتحقق، وتواصل منظم.

.3 — Requirements UX المتطلبات الوظيفية
3.1 المتطلبات المشتركة
• يمكن تصفح المعلمين والبحث قبل تسجيل الدخول.
• تُطلب المصادقة عند تنفيذ إجراءات تتطلب حسابًا مثل حفظ المعلم أو إرسال طلب تواصل أو التقدم
لوظيفة.
• يدعم النظام العربية والإنجليزية مع تبديل واضح واتجاه RTL/LTR صحيح.
• الواجهة متجاوبة على الجوال والتابلت والكمبيوتر.
• لكل دور لوحة تحكم مستقلة بمحتوى واختصارات مناسبة.
• تظهر الإشعارات داخل المنصة، ويمكن إرسالها بالبريد والجوال بحسب إعدادات المستخدم.
• توجد حالات تحميل، وعدم وجود نتائج، والخطأ، والنجاح، مع نصوص واضحة وإرشادات للخطوة التالية.
3.2 البحث والمطابقة
• حقول البحث الأساسية: المادة، الصف، المنطقة، نمط التدريس، والوقت/التوفر.
• تظهر أسئلة إضافية اختيارية عند الحاجة لتحسين دقة المطابقة.
• ترتب النتائج افتراضيًا حسب مدى التطابق.
• خيارات الترتيب: الأكثر تطابقًا، الأعلى تقييمًا، الأكثر خبرة، والأقرب.
• توضح بطاقة النتيجة معلومات عملية قابلة للمقارنة، ولا تُظهر معلومات غير متاحة كأنها مؤكدة.
• عند غياب النتائج، يقترح النظام بدائل قريبة، أو يتيح نشر طلب، أو حفظ البحث وتفعيل تنبيه.
3.3 بطاقة وملف المعلم
• تتضمن البطاقة: صورة، اسم، المادة/الصف، المنطقة، نمط التدريس، الخبرة، التوفر، التقييم،
وحالة التوثيق.
• يمكن فتح ملف المعلم، حفظه، مشاركته، إرسال طلب تواصل، أو إرسال سؤال.
• الملف يعرض نبذة مختصرة والمعلومات العملية الأساسية.
• توضح شارات التوثيق ما تم التحقق منه: الهوية، المؤهل، الخبرة، بحسب الحالة الفعلية.
• لا يظهر رقم الهاتف أو وسيلة الاتصال الخاصة إلا وفق سياسة الخصوصية وبعد قبول طلب التواصل.

3.4 المدارس
• البحث عن معلم وفق حقول البحث والمطابقة.
• نشر وظيفة بتفاصيل الدور والمادة والصف والمنطقة والدوام والمتطلبات.
• إنشاء طلب عاجل عبر مسار سريع، مع خيار استكماله كوظيفة مفصلة.
• متابعة الطلبات واستقبال المتقدمين وإرسال طلبات التواصل.
• تقييم المعلم بعد تعامل فعلي.
3.5 أولياء الأمور
• إرسال نموذج احتياج سريع للمادة والصف والمنطقة والنمط والوقت.
• حفظ المعلمين ومشاركة الملفات وإرسال سؤال أو طلب تواصل.
• نشر طلب عند عدم العثور على معلم مناسب.
• تفعيل تنبيه عند ظهور معلم مطابق.
• تقييم المعلم بعد تعامل فعلي، وفق معايير مخصصة للوالدين.
3.6 المعلمون
• إنشاء ملف عبر خطوات: بيانات شخصية، مؤهلات وخبرة، مواد وصفوف، منطقة ونمط تدريس، جدول توفر،
توثيق.
• عرض نسبة اكتمال الملف وإمكانية العودة لإكماله.
• إدارة جدول أسبوعي مرن وتحديد توفر منفصل للمدارس والدروس الخصوصية.
• استقبال تفاصيل طلب التواصل وقبوله أو رفضه.
• استعراض الطلبات العاجلة والتقدم لها.
• تحديث بيانات الملف والتوثيق والتوفر.
3.7 نموذج الإيرادات
الخدمات الأساسية مجانية. يمكن لاحقًا اختبار خدمات اختيارية مدفوعة، مثل أدوات متقدمة
للمدارس أو إبراز ملف المعلم، مع الحفاظ على عدالة النتائج وعدم ضمان ترتيب متقدم مقابل
الدفع.
.4 المتطلبات غير الوظيفية
• سهولة الاستخدام: نصوص قصيرة، تسميات واضحة، وخطوات قليلة لإنجاز المهمة.
• الثقة والخصوصية: حماية بيانات التواصل، موافقة المستخدم على مشاركة بياناته، ومراجعة طلبات
التوثيق.
• الشفافية: توضيح سبب المطابقة وبيان ما تم توثيقه فعليًا.
• إمكانية الوصول: تباين جيد، أحجام نصوص مقروءة، وعدم الاعتماد على اللون وحده لإظهار الحالة.
• الأداء: صفحات بحث ونتائج سريعة مع مؤشرات تحميل.
• القابلية للتوسع: دعم محافظات ومديريات جديدة دون تغيير هيكل النظام.
• اللغات: دعم اتجاه النص الصحيح وتنسيق الأرقام والتواريخ بحسب اللغة.

5.1 المسار العام
الصفحة الرئيسية ← اختيار مدرسة/ولي أمر/معلم ← التصفح أو التسجيل حسب الإجراء ← تنفيذ المهمة
الأساسية ← متابعة الحالة والإشعارات.
5.2 مسار المدرسة: البحث
الرئيسية ← مدرسة ← تسجيل الدخول عند الحاجة ← لوحة المدرسة ← بحث عن معلم ← تحديد المادة
والصف والمنطقة والنمط والتوفر ← نتائج مرتبة حسب المطابقة ← فتح ملف المعلم ← إرسال طلب
تواصل ← إشعار المعلم بالتفاصيل ← قبول/رفض ← إتاحة التواصل بعد القبول.
5.3 مسار المدرسة: الاحتياج العاجل
لوحة المدرسة أو الصفحة الرئيسية ← أحتاج معلمًا بشكل عاجل ← نموذج سريع للمادة والصف
والمنطقة والتوفر ووسيلة التدريس ← مراجعة الطلب ← إرسال ← إشعار للمعلمين المطابقين وقسم
الطلبات العاجلة ← متابعة المتقدمين والتواصل.
5.4 مسار المدرسة: نشر وظيفة
لوحة المدرسة ← نشر وظيفة ← إدخال تفاصيل الوظيفة ← مراجعة ونشر ← استقبال طلبات المعلمين ←
مراجعة الملفات ← التواصل أو اختيار المرشحين.
5.5 مسار ولي الأمر
الرئيسية ← ولي أمر/البحث عن مدرس ← إدخال المادة والصف والمنطقة والنمط والوقت ← نتائج
مطابقة ← ترتيب/فلترة ← ملف المعلم ← حفظ/مشاركة/سؤال/طلب تواصل. إذا لم توجد نتائج مناسبة:
بدائل + نشر طلب + تفعيل تنبيه.
5.6 مسار المعلم
الرئيسية ← معلم ← إنشاء حساب ← نموذج متعدد الخطوات ← اكتمال البيانات والتوفر ← رفع مستندات
التوثيق ← إرسال للمراجعة/نشر الملف وفق سياسة المنصة ← لوحة المعلم ← إدارة الملف والجدول
والطلبات والإشعارات.
5.7 طلب التواصل
المستخدم يرسل طلبًا مع تفاصيل احتياجه ← يصل إشعار للمعلم ← المعلم يراجع التفاصيل ← قبول أو
رفض ← عند القبول تظهر خيارات التواصل المسموح بها.
5.8 حالات عدم وجود نتائج
نتائج غير كافية ← عرض بدائل مشابهة مع توضيح الفروق ← خيار نشر طلب ← خيار حفظ البحث وتفعيل
إشعار عند ظهور تطابق.

.9 تعليمات تصميم بصرية لـ Stitch
• أنشئ واجهات ويب عربية RTL أولًا، مع دعم الإنجليزية LTR وتبديل اللغة.
• استخدم لوحة ألوان هادئة: بنفسجي فاتح، أبيض، رمادي فاتح للنصوص الثانوية، وبنفسجي أغمق
للأزرار الأساسية.
• استخدم بطاقات بحدود خفيفة وظلال بسيطة وزوايا دائرية، وتجنب ازدحام العناصر.
• اجعل الأزرار الأساسية واضحة وبنصوص فعلية، لا تستخدم نصوصًا تجريبية غير مفهومة.
• اعرض حالات الواجهة: افتراضية، hover/focus إن أمكن، تحميل، خطأ، ونتائج فارغة.
• صمم مكونات قابلة لإعادة الاستخدام: Header، بطاقة دور، بطاقة معلم، شارة توثيق، شارة توفر،
زر أساسي، حقل بحث، بطاقة طلب.
• لا تضع معلومات شخصية حقيقية؛ استخدم بيانات تجريبية واضحة.
• لا تعرض شارة موثّق إلا للملفات التي تحمل حالة توثيق واضحة، ولا تضمن أن الدفع يرفع ترتيب
المعلم.
• ابدأ بتصميم الواجهات الثلاث المذكورة، ولا تنشئ صفحات إضافية قبل تثبيت الأسلوب البصري.
.10 معايير قبول التصميم
• يفهم المستخدم خلال ثوانٍ أن المنصة تخدم المدارس وأولياء الأمور والمعلمين.
• تظهر الأدوار الثلاثة بالتساوي في الصفحة الرئيسية.
• يمكن الوصول إلى البحث عن معلم أو الطلب العاجل أو إنشاء ملف المعلم من خطوات قليلة.
• الصفحة قابلة للاستخدام على شاشة جوال ضيقة وعلى الكمبيوتر.
• تكون أولوية المطابقة والتوثيق والتوفر مفهومة بصريًا.
• لا يلتبس على المستخدم ما إذا كان التسجيل مطلوبًا للبحث أو للتواصل.
• توضح الحالات الفارغة الخطوة التالية: بدائل، نشر طلب، أو تنبيه.
• تظل الواجهة قابلة للتوسع لمحافظات جديدة ولخدمات إضافية.
.11 افتراضات وقرارات تحتاج حسمًا لاحقًا
• الاسم «وصل التعليمية» اسم عمل مقترح في هذه الوثيقة، ويمكن استبداله بالاسم النهائي.
• تفاصيل الأسعار والخدمات المدفوعة لم تُحسم؛ يبدأ التصميم بالخدمات الأساسية المجانية.
• سياسة التحقق من الهوية والمؤهلات تحتاج إجراءات تشغيل واضحة قبل إطلاق شارة التوثيق.
• آلية الدفع أو الحجز ليست جزءًا مؤكدًا من النسخة الأولى؛ التواصل يتم بعد قبول الطلب.
• إشعارات الجوال قد تعتمد على إمكانات الويب أو التطبيق الذي سيُبنى لاحقًا.
